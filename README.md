# Bonus Bot 🎁

A fun Telegram bot that gives daily virtual bonus points with streaks, levels, and leaderboards.

## Features
- 🎁 Daily bonus claims
- 🔥 Streak multipliers
- 🏅 Level system (Starter → Legendary)
- 🏆 Leaderboard competition
- 📊 Personal statistics

## Commands
- `/start` - Main menu
- `/bonus` - Claim daily bonus
- `/stats` - View your stats
- `/leaderboard` - View top users
- `/help` - Help menu

## Deployment
Deployed on Railway with GitHub integration.

## Tech Stack
- Python 3.11+
- pyTelegramBotAPI
- Railway
